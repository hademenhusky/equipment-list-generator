## 手动复验

1. 打开 `index.html`，新建项目，选择相机，添加手动镜头并输入数量，走完向导。
2. 确认所有来源为待确认。批量设置租赁，再把首项改为公司并修改数量，完成编辑。
3. 导出全部，在 Excel 或兼容软件检查三张工作表；未报价设备应显示待询价。
4. 刷新页面，从历史恢复，核对刚才修改的数量及来源。
5. 粘贴 `FX3两台`、`RS4 x1`、`电池6块`、`神秘镜头1支`（每行一项），核对陌生型号提示并生成。
6. 使用手机或浏览器响应式模式检查导航和编辑表格。
